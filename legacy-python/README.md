# Gift Price Parser — MRKT · Portals · Fragment · Telegram · Tonnel

GUI и CLI для поиска **реальной цены** апгрейд-подарка Telegram: выбираешь коллекцию
(и, если нужно, модель/фон/символ) — получаешь историю сделок сразу с нескольких
площадок, медиану, средние без выбросов, текущие флоры и график с карточкой подарка
при наведении.

## Площадки

| Источник | История сделок | Активные лоты | Вход в Telegram | Как получаем |
|----------|----------------|---------------|-----------------|--------------|
| **MRKT** | да, вся лента | да | нужен | `api.tgmrkt.io` — `POST /api/v1/feed` |
| **Portals** | да, вся лента | да (публично) | нужен для истории | `portal-market.com/api/market/actions/` |
| **Fragment** | до 60 последних сделок | да | не нужен | HTML `fragment.com/gifts/<slug>?filter=sold&sort=listed` |
| **Telegram** | нет (API не отдаёт) | да + официальная оценка | нужен | MTProto `payments.getResaleStarGifts` |
| **Tonnel** | да, вся история | да | нужен | `gifts3.tonnel.network` — `POST /api/saleHistory` |

Подробности всех роутов и форматов — в [API.md](API.md).

Про Getgems: их GraphQL закрыт (`GRAPHQL_STRANGE_QUERY`, публичный API — только по ключу),
а on-chain истории у этих подарков практически нет — проверка через TonAPI по десятку
экземпляров Heroic Helmet дала 0 событий `NftPurchase` (подарки торгуются вне блокчейна,
в кастодиальных маркетах). Поэтому Getgems как источник цен не подключён.

## Установка

```bash
pip install -r requirements.txt
```

В `.env` рядом с проектом лежат ключи Telegram (`API_ID` / `API_HASH` с
[my.telegram.org](https://my.telegram.org)). Поддерживается и `KEY=VALUE`, и `KEY: VALUE`.

## Вход в Telegram (один раз)

```bash
python cli.py login
```

Номер, код и пароль 2FA вводишь сам — сохраняется только файл сессии `tg_session.session`.
Дальше initData для мини-аппов выпускается автоматически и кешируется в `.cache/` на 40 минут.

Проверить все площадки:

```bash
python cli.py probe
```

## GUI

```bash
python run_gui.py
```

* **Поиск коллекции/модели/фона/символа** — по любому слову, не обязательно с начала:
  «helm» → Heroic Helmet и Neko Helmet, «hunter» → модель Bounty Hunter. В списке видно
  картинку, название и флор (для фонов — свотч настоящего цвета из Telegram).
  Список привязан к окну приложения: закрывается кликом в любом месте программы,
  при перемещении окна и по Escape. Enter подставляет верхнее совпадение, а не «любой».
* **Подгрузка на прокрутке**: первый экран — по 20 самых свежих сделок сразу со всех
  площадок (MRKT + Portals + Fragment + Tonnel), дальше при прокрутке добирается
  следующая страница с каждой. Ограничения «сколько событий» больше нет.
* **Реальное время**: выбора периода нет — берётся вся история, а каждые 20 секунд
  подтягиваются новые сделки (и раз в минуту — флоры). Список всегда отсортирован по
  времени; если ты сам отсортировал по другой колонке, порядок сохраняется. Выключается
  галочкой «Обновлять в реальном времени».
* **Цена в USDT и звёздах**: у каждой сделки цена пересчитывается по курсу TON **на день
  сделки** (не по сегодняшнему), поэтому старые сделки видно честно. В основном поле —
  сколько звёзд нужно **купить** (1 ★ = $0.0150); в карточке подарка на графике второй
  строкой — сколько получит продавец за звёзды (1 ★ = $0.0118). Подписи жёлтые со звёздочкой.
* **Карточки сверху**: медиана, средняя без выбросов, последняя продажа, диапазон,
  число сделок, лучший флор — под каждой ценой подпись `$…` и `… ★`; строкой ниже —
  флоры всех площадок в TON и $, оценка Telegram и текущий курс TON.
* **График**: точки сделок по времени, цвет = площадка. При наведении на точку —
  карточка с картинкой подарка на его фоне, ценой в TON/$/★, площадкой, датой и
  атрибутами; она всегда остаётся в пределах экрана и исчезает, когда уводишь курсор.
* **Таблица** сортируется кликом по заголовку, двойной клик открывает `t.me/nft/...`.
* «Экспорт CSV» сохраняет всё найденное, «Обновить каталог» — перечитывает список
  коллекций и атрибутов из Portals.

## CLI

```bash
python cli.py sources                       # какие площадки что умеют
python cli.py update-data                   # дотянуть data.json до полного списка (бэкап рядом)
python cli.py images --collection finepen   # догрузить картинки моделей и символов
python cli.py rates                         # курс TON/USD, история и цена в звёздах
python cli.py collections --filter helmet
python cli.py attrs "Heroic Helmet" --filter tiger
python cli.py search "Heroic Helmet" --model "Bengal Tiger" --days 90
python cli.py search "Fine Pen" --sources portals,fragment --csv pen.csv
```

Флаги `search`: `--model`, `--backdrop`, `--symbol`, `--days` (0 = без ограничения),
`--limit`, `--sources` (`mrkt,portals,fragment,telegram,tonnel`), `--all-events`, `--show`, `--csv`.

## Данные и картинки

* `data.json` — каталог: `collections[<short>]` с моделями/символами/фонами, `floor_prices`
  и `meta` (название, id, флор, supply, объём). Формат совместим с твоим `main.py`.
  Было 107 коллекций, после `update-data` — 120 (добавились Fine Pen, Algorithm Cup,
  Rare Bird, Chill Flame, Vice Cream, Liberty Figure, Mood Pack, Pool Float, Surge Board,
  Timeless Book, Victory Medal, Intelligence Cup, Durov's Glasses).
* `downloaded_collections/<short>/<Модель>.png` — картинки (их качает твой `main.py`,
  а парсер докачивает недостающие сам, по мере надобности).
* `gift_parser/backdrops.json` — 80 фонов с настоящими цветами (center/edge/pattern/text),
  выгружены из Telegram; из них рисуется фон в карточке подарка.
* `ton_usd.json` — курс TON в долларах по дням за 2 года (730 дней, от $1.22 до $6.90):
  длинный хвост с Binance + свежие 365 дней с CoinGecko. Недостающие даты догружаются
  на лету и дописываются в файл.

## Как читать результат

* **Медиана** — главный ориентир: одна случайная сделка её не сдвинет.
* **Средняя без выбросов** — среднее после отсечения хвостов по правилу Тьюки (1.5·IQR).
* **Флор** — минимальная активная цена продажи; медиана сделок — за сколько реально уходит.
  Официальный маркет Telegram обычно дороже MRKT/Portals — это нормально.
* Цена зависит прежде всего от модели. Ищи с указанной моделью, иначе смешаются
  лоты за 170 и за 900 TON.

## Ограничения

* Fragment ищет только по **одному** атрибуту: если задать и модель, и фон — источник
  пропускается с пометкой в статусе (иначе в статистику попали бы чужие сделки).
* Официальный маркет Telegram истории сделок не отдаёт — только активные лоты и оценку
  (в валюте твоего аккаунта, у тебя UAH).
* Tonnel считает продажами только `INTERNAL_SALE`; ставки на аукционах (`BID`) в
  статистику не идут. Раньше площадка резала запросы Cloudflare — сейчас отвечает нормально.
* `.env`, файл сессии и `.cache/` не коммитятся (см. `.gitignore`).
